# Home de Olimpo · referencia para Wrapped 2026

Esta carpeta contiene una copia aislada de la home adaptable de `olimpo-interactive-walktrough`. Se extrajeron el header, el carrusel principal, los módulos de home, el footer, el menú de perfil y la navegación móvil. Se omitieron la pantalla de activación de cuenta y las capas del recorrido de onboarding.

La página abre directamente en el estado autenticado simulado que usa la demo fuente. Los datos de partidos, cuotas y perfil son contenido de muestra; los botones de cuotas no ejecutan apuestas.

## Abrir

Sirve esta carpeta con cualquier servidor HTTP estático y abre `index.html`. No requiere dependencias de npm ni una compilación.

## Contenido

- `index.html`: estructura extraída de la home y el menú de perfil.
- `styles.css`: estilos de la demo fuente para conservar con fidelidad el diseño y sus breakpoints.
- `home.js`: carrusel, apertura/cierre del menú, escala de grises del logo y estado activo de navegación móvil.
- `assets/`: tipografías, banners y recursos locales de la demo.
